# Using-Bootstrap
Учебный проект: веб-интерфейс для бронирования конференц-залов. Реализована адаптивная верстка, навигация и клиентская валидация форм с использованием HTML5, CSS3 и Bootstrap 5.

# Веб-интерфейс для оформления заявок на конференции

Учебный проект, разработанный в рамках обучения по специальности «Информационные системы и программирование». Представляет собой прототип клиентской части сайта для бронирования помещений под конференции.

## Функционал проекта
- **Страница регистрации**: форма сбора данных пользователя (логин, пароль, ФИО, телефон, email).
- **Страница авторизации**: форма входа с валидацией и чекбоксом «Запомнить меня».
- **Страница оформления заявки**: выбор помещения, ввод даты, времени и персональных данных.
- **Валидация форм**: реализована на стороне клиента с использованием нативных атрибутов HTML5 и стилей Bootstrap.
- **Адаптивность**: корректное отображение на мобильных устройствах, планшетах и десктопах (включая навигационное меню-бургер).

## Используемые технологии
- **HTML5** (семантическая верстка, валидация форм)
- **CSS3** (стилизация, эффекты)
- **Bootstrap 5** (сетка, формы)
- **JavaScript** (включение режима валидации Bootstrap через `was-validated`)

## Структура проекта
- `registration.html` — страница регистрации пользователя
- `login.html` — страница авторизации
- `request.html` — страница оформления заявки на конференцию

## Демонстрация
Проект не требует сборки или установки зависимостей. Все внешние библиотеки подключены через CDN. 
Для просмотра достаточно открыть любой из HTML-файлов.
